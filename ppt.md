## Slide 2: The Problem
**Title:** The Friction in Electronics Repair
- **Lack of Transparency:** Consumers struggle to find upfront pricing for device repairs.
- **Trust Deficit:** Finding verified and skilled local technicians is difficult.
- **Poor Tracking:** Traditional repair shops lack real-time order tracking.
- **Lost Business:** Local technicians struggle with visibility against large service centers.

## Slide 3: The Solution
**Title:** Introducing Fixly
- A dual-sided marketplace connecting consumers with neighborhood repair experts.
- Map-based discovery for hyper-local convenience.
- Transparent quoting and seamless booking system.
- Real-time job triage and order lifecycle tracking.

## Slide 4: Key Features for Consumers
**Title:** Empowering the Customer
- **Interactive Map:** Discover nearby shops using CartoDB Voyager tiles.
- **Category Filtering:** Easily find specialists for Mobile, Laptop, AC, etc.
- **Transparent Pricing:** View estimated base costs before booking.
- **Customer Portal:** Track requests from 'Pending Quote' to 'Completed'.
- **Verified Ratings:** Post-repair rating system to ensure quality.

## Slide 5: Key Features for Technicians
**Title:** Equipping the Repair Experts
- **Technician Dashboard:** Manage earnings and track revenue.
- **Dynamic Pricing:** Set custom base rates for different electronic categories.
- **Order Triage:** Accept, quote, or reject incoming requests instantly.
- **Status Updates:** One-click transitions from 'In-Progress' to 'Completed'.

## Slide 6: Technology Stack
**Title:** Built for Speed and Scale
- **Frontend:** React 19, Vite, Tailwind CSS v4, Framer Motion.
- **Mapping:** React-Leaflet with custom styled overlays.
- **Backend:** Node.js, Express.js REST API.
- **Database:** MongoDB with Mongoose Schema validation.
- **Architecture:** Context API for state management, strict MERN separation.

## Slide 7: Business Impact
**Title:** Why Fixly Matters
- Boosts the local repair economy by empowering neighborhood technicians.
- Reduces e-waste by making repairs more accessible and transparent.
- Standardizes the fragmented electronics repair market.

## Slide 8: Future Roadmap
**Title:** What is Next
- Integrated payment gateways for in-app settlements.
- Real-time chat between consumers and technicians.
- AI-powered hardware diagnostic suggestions.
